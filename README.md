# ToDo Application — PSI Lab 1

Aplicația **ToDo** este o aplicație destinată gestionării și organizării sarcinilor într-un mod simplu și eficient.

Utilizatorii au posibilitatea de a:

* **Adăuga sarcini noi**, specificând prioritatea acestora la momentul creării.
* **Atribui taguri** fiecărei sarcini pentru o organizare și identificare mai ușoară.
* **Încadra sarcinile în categorii**, în funcție de tipul acestora.
* **Modifica sarcinile existente** atunci când este necesar.
* **Șterge sarcinile** care nu mai sunt necesare.
* **Vizualiza toate taskurile** într-o pagină dedicată, cu posibilitatea de a le filtra după status:

  * Toate taskurile
  * Taskuri care trebuie realizate
  * Taskuri aflate în progres
  * Taskuri finalizate

### Dashboard

Aplicația include și un **Dashboard** unde utilizatorul poate avea o imagine de ansamblu asupra activității sale.

Pe Dashboard sunt disponibile:
* Un **chart** care prezintă numărul de taskuri create în diferite intervale de timp.
* Lista **taskurilor programate pentru ziua curentă**.
* O vizualizare rapidă a activității și progresului taskurilor.
